# 006. 공용 문구·상수는 src/constants에 둔다

## 상태

- Accepted

## 맥락

토스트 문구("삭제했습니다." / "삭제하지 못했습니다. 다시 시도해주세요." 등)가 6개 화면, 30곳에 문자열로 흩어져 있었다. 같은 의미의 문구가 화면마다 달라지기 쉽고, 문구를 바꾸려면 모든 화면을 찾아다녀야 했다.

## 결정

여러 화면이 함께 쓰는 문구·상수는 `src/constants/`에 둔다. 첫 파일은 `src/constants/toastMessages.ts`(`TOAST_MESSAGES`)이고, 토스트를 띄울 때는 문자열 대신 이 상수를 쓴다.

## 근거

- 문구를 한곳에서 바꿀 수 있고, 화면 간 표현이 통일된다.
- 테스트는 기존처럼 화면에 보이는 문자열로 확인할 수 있다(상수 값이 곧 문구).

## 대안

- 페이지마다 문자열 유지: 지금처럼 중복과 표현 차이가 생긴다.
- 모든 상수를 `src/constants`로 이동: 한 도메인에서만 쓰는 상수(예: `src/pages/projects/projects.constants.ts`의 백엔드 enum 옵션)까지 옮기면 쓰는 곳과 멀어진다. `code-style.md`의 "재사용되기 전까지는 기능 근처에 둔다"와 충돌해 택하지 않았다.

## 영향

- 새 토스트 문구는 `TOAST_MESSAGES`에 추가하고 키로 참조한다.
- 한 도메인 전용 상수는 그 기능 근처에 두고, 여러 도메인이 쓰게 되면 `src/constants`로 옮긴다.
- 관련 규칙: `.claude/rules/architecture.md` 파일 배치 표
